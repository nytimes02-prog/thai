# พูดเลย 태국어 회화 · 무료판 사용법

AI는 구글 Gemini 무료 키를 쓰고, 말 알아듣기와 읽어 주기는 브라우저에 들어 있는 기능을 써요. 돈은 들지 않아요.

## 1. 무료 키 받기 (한 번만)
1. 구글 계정으로 https://aistudio.google.com/app/apikey 에 들어가요.
2. 'API 키 만들기(Create API key)'를 눌러요. 카드 등록은 필요 없어요.
3. 만들어진 키(AIza로 시작)를 복사해요.
4. 페이지 맨 위 칸(또는 설정 → 무료 AI 키)에 붙여 넣고 '키 확인하고 저장'을 눌러요.

- 키는 그 기기 브라우저에만 저장되고 구글 서버로만 보내져요. 페이지 파일 안에는 키가 들어가지 않아요.
- 휴대폰과 PC는 각자 한 번씩 넣어야 해요.
- 무료 사용량에는 분당·하루 횟수 제한이 있어요. 구글이 자주 바꾸기 때문에 정확한 숫자는 AI Studio에서 확인해 주세요. 한도에 걸리면 잠시 기다리거나, 설정에서 이름에 'lite'가 붙은 모델로 바꾸세요.

## 2. PC에서 열기
`index.html`을 크롬이나 엣지로 열면 돼요. 이 경우 화면 켜두기는 작동하지 않고, 마이크 허용을 자주 물을 수 있어요. 아래 3번처럼 인터넷 주소로 올리면 둘 다 해결돼요.

## 3. 휴대폰에서 쓰기 (PC가 꺼져 있어도, LTE로도)
휴대폰에서 마이크를 쓰려면 페이지가 https 주소에 있어야 해요. 무료인 GitHub Pages를 추천해요.
1. https://github.com 에 가입해요(무료).
2. 오른쪽 위 + → New repository를 누르고, 이름을 `thai`로 정하고 Public을 고른 뒤 Create를 눌러요.
3. 'uploading an existing file'을 눌러 이 폴더의 `index.html`을 끌어다 놓고 Commit changes를 눌러요.
4. 저장소의 Settings → Pages에서 Branch를 `main`으로 고르고 Save를 눌러요.
5. 1~2분 뒤 `https://내아이디.github.io/thai/` 주소가 생겨요. 휴대폰에서 이 주소를 열어요.
6. 홈 화면에 두기: 안드로이드 크롬은 ⋮ → '홈 화면에 추가', 아이폰 사파리는 공유 → '홈 화면에 추가'.

공개 저장소라도 키는 파일에 없어서 안전해요. 주소를 아는 사람은 각자 자기 키를 넣어야 쓸 수 있어요.

## 4. 음성 대화
- 아래쪽 **음성 대화** 버튼을 눌러요. 마이크 권한을 물으면 **'허용'**을 눌러야 해요.
- 큰 마이크 버튼을 누르고 말하면 알아듣고, AI 대답을 태국어로 읽어 줘요. '한국어 뜻도 읽기'를 켜면 뜻도 한국어로 읽어 줘요.
- **자동으로 이어 듣기**를 켜 두면, 대답을 다 읽은 뒤 저절로 다시 들어요. 손을 쓰지 않고 주고받을 수 있어요. 세 번 연속 말이 없으면 쉬어요.
- '태국어로 말하기 / 한국어로 말하기' 중 지금 말할 언어를 골라요. 음성 인식은 한 번에 한 언어만 알아들어요.
- 끄기: **'음성 대화 끄기'** 버튼, 또는 아래쪽 '음성 대화' 버튼을 다시 누르세요.
- 마이크를 거절했다면 주소창 왼쪽 자물쇠(아이폰 사파리는 aA) → 마이크 → 허용으로 바꿔요.

| 기기 | 말 알아듣기 | 읽어 주기 | 비고 |
|---|---|---|---|
| PC 크롬·엣지 | 됨 | 됨 | 태국어 음성이 없으면 Windows 설정 → 음성 → 음성 추가 → 태국어 |
| 안드로이드 크롬 | 됨 | 됨 | 소리가 안 나면 Google 음성 서비스에서 태국어 데이터 받기 |
| 아이폰 사파리 | 대부분 됨 | 됨 | 자동으로 이어 듣기가 막히면 큰 버튼을 눌러 말하세요. 설정 → Siri에서 받아쓰기가 켜져 있어야 할 수 있어요 |
| 파이어폭스, 카카오톡 안 브라우저 | 안 됨 | 됨 | 키보드의 마이크 버튼으로 말해서 입력하고 '보내기' |

음성 인식은 브라우저 회사(구글·애플) 서버를 거치기 때문에 인터넷이 연결돼 있어야 해요.

## 5. 켜 두기와 끄기
- 위쪽 **전구 버튼**: 켜 두면 이 페이지를 보는 동안 화면이 꺼지지 않아요. 다시 누를 때만 꺼져요.
- 휴대폰에서 다른 앱으로 가면 브라우저가 페이지를 멈춰요. 운영체제 규칙이라 막을 수 없어요. 돌아오면 대화가 그대로 남아 있어요.
- PC에서 Windows를 켤 때마다 열고 싶으면, 3번에서 만든 주소를 엣지 '앱으로 설치(⋯ → 앱 → 이 사이트를 앱으로 설치)'로 설치한 뒤 '로그인할 때 자동 시작'을 켜면 돼요.
