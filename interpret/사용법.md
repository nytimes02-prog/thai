# ล่าม 한·태 자동 통역 사용법

한국어로 말하면 **태국어 목소리**로, 태국어로 말하면 **한국어 목소리**로 바꿔 읽어 줘요.
휴대폰을 두 사람 사이에 두고 번갈아 말하면 돼요.

## 1. 처음 한 번: 무료 AI 키
태국어 회화 무료판과 같은 구글 Gemini 무료 키를 써요.
1. https://aistudio.google.com/app/apikey 에서 'API 키 만들기'를 눌러요. 카드 등록은 필요 없어요.
2. 키(AIza…)를 복사해서 페이지 맨 위 칸에 붙여 넣고 '키 확인하고 저장'을 눌러요.

무료판과 같은 주소(같은 GitHub Pages 저장소)에 올리면 키를 한 번만 넣으면 돼요.

## 2. 쓰는 법
- **자동 감지**: '시작'을 누르고 그냥 말해요. 한국어인지 태국어인지 AI가 알아서 구분해요. 말이 끝나고 잠깐 멈추면 통역해서 읽어 줘요. 끝내려면 '멈추기'를 눌러요.
- **눌러서 말하기**: 시끄러운 곳에서 써요. '한국어로 말하기' 또는 'พูดภาษาไทย'를 누른 뒤 말해요.
- **글로 쓰기**: 아래 칸에 한국어나 태국어를 쓰고 '번역'을 눌러요.
- 카드의 '크게 보여주기'를 누르면 상대에게 화면으로 보여 줄 수 있어요.
- 마이크 권한을 물으면 **'허용'**을 눌러요.

## 3. TV가 켜진 곳에서
- 아무도 말하지 않을 때 **'주변 소리 재기'**를 눌러 3초 동안 TV 소리 크기를 재 두세요. 그보다 확실히 큰 목소리만 들어요.
- 설정 → 마이크 민감도 → **'가까운 목소리만'**으로 바꾸고, 휴대폰에 대고 말하세요.
- AI도 TV·라디오처럼 들리는 배경 소리는 통역하지 않고 넘겨요.
- 그래도 잡히면 **'눌러서 말하기'**를 쓰세요. TV 속 사람이 또렷하게 말하면 가끔 잡힐 수 있어요.

## 4. 소리가 안 나올 때
- 태국어 목소리: 휴대폰 설정 → 언어/음성(텍스트 음성 변환)에서 **태국어**를 추가해요.
  - Windows PC: 설정 → 시간 및 언어 → 음성 → 음성 추가 → 태국어
- 한국어 목소리도 같은 방법으로 **한국어**가 있어야 해요.
- 아이폰은 무음 스위치가 켜져 있으면 소리가 작거나 안 날 수 있어요.

## 5. 휴대폰에서 쓰려면
휴대폰 마이크는 https 주소에서만 돼요. 태국어 회화 무료판 사용법의 3번처럼 GitHub Pages 저장소에 올리세요.
이 파일은 저장소 안에 `interpret` 폴더를 만들어 `index.html`로 올리면 `https://내아이디.github.io/thai/interpret/` 주소가 돼요.

## 6. 알아 둘 점
- 말 한 번이 무료 한도에서 한 번으로 세어져요. 한도에 걸리면 잠시 기다리거나 설정에서 'lite' 모델로 바꿔요.
- 통역은 말이 끝난 뒤 1~3초쯤 걸려요.
- 휴대폰이 읽어 주는 동안에는 듣기를 잠깐 멈춰요. 자기 목소리를 다시 통역하지 않게 하려고요.
- 인터넷이 연결돼 있어야 해요.
